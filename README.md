# RISC-V Journey 🚀

A personal journey of building a complete RISC-V CPU from scratch — starting from logic gates all the way to a fully functioning processor.

> *"What I cannot create, I do not understand."* — Richard Feynman

## 🎯 Goal

To deeply understand computer architecture by building every component by hand — from a simple Full Adder to a complete RISC-V CPU and beyond.

## 🧠 About This Journey

This repository documents my self-taught path into computer architecture and hardware design. Every project builds on the previous one — from the smallest logic gate to a complete processor.

The end goal: design powerful, efficient processors capable of running AI workloads at minimal power consumption.
